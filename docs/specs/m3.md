# M3 · Attribution and trace: implementation spec

Status: ready to build · Covers PLAN.md §7 M3 (six items) · Read with ARCHITECTURE.md, DESIGN.md and
`docs/specs/m1.md` / `m2.md` (their conventions still apply: URL hash state, `*State.ts` pure helpers with vitest
tests, backend tests in `backend/tests/test_*_m3.py`, old runs must still open).

## 0. Current data flow (what M3 changes)

```
TraceView "Run attribution"
  └─ POST /attribution {method, target, steps}  ──▶ RunManager.attribution (sync, under _lock)
        cache attribution/<method>_<target|top>_<steps>.json
        attribute(): capture.op_gradients (TorchLens backward of logits[0,target]) → scores, channel_scores
                     input_attribution (Captum IG | Saliency | InputXGradient on to_logits(model(x)))
  └─ GET /graph?method=&target=&steps= ──▶ graph_view(ir, depth, scores) → attach_scores:
        share(edge) = |source node score| / Σ over the target's incoming edges     ← first-order, wrong at merges
        path = greedy walk from the output node along the max share
```

Verified against the installed packages (torchlens 2.34.1, captum 0.9.0) while writing this spec:

- **Merge contributions.** A TorchLens `save_grads` trace gives every op `func`, `parent_arg_positions`
  (`{"args": {0: "relu_1_2", 1: "conv2d_3_5"}}`; nested keys like `(0, 1)` for `cat([a, b])`),
  `non_tensor_pos_args`, `non_tensor_kwargs` and `grad`. You can re-call `func` on cloned parent leaves and take
  `autograd.grad(y, leaves, grad_out)` to get each parent's grad×input *through that merge*. On ResNet-18, the
  `iadd_1_10` contributions are `{bn: 0.346, identity: 0.788}` and they sum exactly to the merge's own grad×act
  (1.134). The old share used the identity's *own* total, 1.134, which also counts flow through the conv branch.
- **Patching.** Use `tl.trace(..., intervention_ready=True)`, then
  `trace.do(tl.label(op_label), tl.replace_with(t), engine="replay", confirm_mutation=True)`. This replays the
  recorded DAG and updates every downstream `op.out`. The logits match a plain `register_forward_hook` replacement
  exactly. Live hooks (`tl.trace(hooks=...)`) reject finalized labels, so don't use them.
- **Internal objective.** `trace.log_backward(first_tensor(op.out)[0, c].sum())` works for any op. Ops downstream
  of the unit get no grad.
- **Layer methods.** `LayerIntegratedGradients` / `LayerConductance` both return `(B, C, H, W)` and a convergence
  delta. Captum's `NeuronConductance` refuses aggregated neurons (a callable selector "should NOT aggregate"), so
  the spatially summed channel conductance is implemented directly (§3.3).

M3 keeps every new response bounded, as before. Attribution maps are ≤ 24×24. Per-channel vectors are ≤ C (a
few thousand). Patch deltas are one float per op. Agreement results are n×n matrices with n ≤ 3.

Compatibility: runs captured before M3 open unchanged. Cached attribution files without a `merges` key are
treated as stale and recomputed. There is no new run artifact apart from the new cache files (§1.7).

## 1. Backend (package A)

### 1.1 `jobs.py` (new): generic in-process job runner

```python
class Cancelled(Exception): """Raised by the progress callback once cancel was requested."""

Progress = Callable[[float, str], None]   # progress(fraction 0..1, message); raises Cancelled when cancelled

TERMINAL = ("done", "error", "cancelled")

@dataclass
class Job:
    id: str                 # "job_000001", a process-wide counter
    kind: str               # free text; M3 uses attribution | layer | neuron | agreement | patch (M4 adds capture)
    run_id: str | None
    key: str | None         # dedup key (the cache file name); None = never dedup
    status: str = "queued"  # queued | running | done | error | cancelled
    progress: float = 0.0
    message: str = ""
    result: Any = None
    error: str | None = None
    created: float = 0.0
    version: int = 0        # bumped on every change; SSE waits on it
    cancel_requested: bool = False
    def to_json(self) -> dict  # every field except key/version/cancel_requested

class JobRunner:
    def __init__(self, keep: int = 100)                  # keep the newest `keep` finished jobs in memory
    def submit(self, kind, fn: Callable[[Progress], Any], run_id=None, key=None) -> Job
        # a queued/running job with the same key is returned instead of a new one
    def finished(self, kind, result, run_id=None) -> Job  # a job born "done" (cache hit); never queued
    def get(self, job_id) -> Job                          # KeyError when unknown
    def cancel(self, job_id) -> Job   # queued → cancelled at once; running → flag, ends at the next progress() call
    def wait(self, job_id, version: int, timeout: float) -> tuple[dict, int]
        # returns (job json, version) as soon as job.version != version, else after `timeout` with the same version
```

- There is one daemon worker thread, started on the first `submit`, fed by a `queue.Queue`. **One job runs at a
  time.** Jobs call RunManager methods, and those still take `RunManager._lock`, so a synchronous capture
  (`POST /api/runs`) and a job never overlap on the GPU. The worker itself never takes `_lock`, because it is not
  re-entrant and the manager methods acquire it themselves.
- On success the worker sets `status="done"`, `progress=1`, `result=fn(progress)`. On `Cancelled` it sets
  `"cancelled"`. On any other exception it sets `"error"` and `error=str(e)` (or the exception type name when the
  message is empty).
- State changes go through one `threading.Condition`. Every change bumps `version` and calls `notify_all`.
- `# ponytail: one worker, in-memory jobs; persist or add GPU/CPU lanes when M4 captures need it.`

### 1.2 `capture.py` (the only TorchLens-aware file)

**(a) `op_gradients`** gets an objective and merge contributions:

```python
def op_gradients(model, inputs, target, to_logits, objective: dict | None = None) -> dict:
    """objective None: back-propagate logits[0, target] (target None → argmax), as today.
    objective {"op": op_id, "channel": c}: back-propagate first_tensor(op.out)[0, c].sum().
    Returns {"target", "logit", "value", "scores", "channel_scores", "merges"}."""
```

- `value` is the scalar that was back-propagated. `logit` equals `value` for a logit objective and is `None` for a
  unit objective. `target` is `None` for a unit objective. An unknown `op` id raises
  `ValueError(f"Unknown op {op}")`, and a channel out of range on axis 1 raises `ValueError`.
- `merges: {child_op: {parent_op: float}}` covers every visible op with **≥ 2 distinct visible parents** and a
  grad. The algorithm, as verified in §0:
  1. Clone each visible parent's `out` as a `requires_grad` leaf. Non-visible parents (buffers) keep their `out`
     as a constant.
  2. Rebuild the positional args from `parent_arg_positions["args"]`. An int key puts the leaf there. A tuple
     `(i, j)` builds a list at position `i`. Fill the remaining positions from `non_tensor_pos_args` in order. Pass
     `leaf.clone()`, never the leaf itself, so in-place funcs like `__iadd__` work.
  3. Compute `y = op.func(*args, **non_tensor_kwargs)` and
     `grads = torch.autograd.grad(first_tensor(y), leaves, first_tensor(op.grad), allow_unused=True)`.
  4. The contribution of each parent is `float((g * leaf).sum())`, with 0 for an unused grad. A parent that
     appears twice (`x + x`) gets one leaf, so its contributions add up.
  - Any exception for one op skips that op, which then falls back to the legacy share (§1.3). Run this under
    `torch.enable_grad()`.
- The docstring states the invariant: for linear merges (add, sub, cat, stack) the contributions of an op sum to
  its own grad×act score.

**(b) `patch`** (new):

```python
def patch(model, inputs, op_id: str, replace: Callable[[torch.Tensor], torch.Tensor], keep=()) -> dict:
    """Re-run the forward pass with op_id's output replaced (TorchLens DAG replay).
    Returns {"deltas": {op: ‖after − before‖₂}, "rel": {op: ‖Δ‖ / ‖before‖ (0 when ‖before‖ = 0)},
             "after": {op: tensor for op in keep}, "logits_after": first tensor of the output op}"""
```

- Run `tl.trace(model, args, layers_to_save="all", intervention_ready=True, unwrap_when_done=True)` inside the same
  `warnings` suppression as `_run_trace`. Then `before = {id: first_tensor(out).detach().clone()}`, taken before
  the replay mutates anything.
- Map the Neurotome id back to the TorchLens label: the op's `op.label`, the pass-qualified label, for `.pN` ids,
  otherwise `layer_label`. Then call
  `trace.do(tl.label(label), tl.replace_with(replace(before[op_id])), engine="replay", confirm_mutation=True)`.
- Deltas cover every visible float op whose after-shape equals its before-shape (computed in float32). Upstream
  ops come out as 0. An unknown op raises `ValueError`. A replacement whose shape differs from the original raises
  `ValueError("replacement shape … != …")`.
- If replay fails, the exception propagates and the job shows it. Don't add a hook fallback.

### 1.3 `graph.py`

- `graph_view(ir, depth=2, scores=None, expand=(), collapse=(), merges=None, start=None)`. The first five
  parameters keep their meaning. In step 4 (edges), also collect **every** op pair that creates an edge, not only
  the first: `pairs[(s, t)] = [(parent_op, child_op), …]`. Pass `merges`, `pairs`, `start` and `node_of` on to
  `attach_scores`. Don't serialise `pairs`.
- `attach_scores(view, scores, merges=None, pairs=None, start=None, node_of=None)`:
  - Node `score` and `score_norm` are unchanged.
  - For a target node with **≥ 2** incoming edges: an edge's flow is
    `Σ |merges[c][p]|` over its pairs `(p, c)` where `c in merges and p in merges[c]`. If **every** incoming edge
    has at least one such pair and the flows sum to more than 0, then `share = flow / Σ flow` and
    `share_method = "merge"`. Otherwise all incoming edges of that target use the legacy rule
    `|source score| / Σ`, with `share_method = "parent"`. With `merges=None` the result is exactly the M2 output
    plus `share_method = "parent"`.
  - A target with a single incoming edge keeps `share = 1.0` and gets no `share_method`.
  - The dominant path starts at `node_of[start]` when `start` is given (the unit objective's op), otherwise at
    the output node. The greedy walk itself is unchanged.
- `module_site(ir, op_id) -> tuple[str, int] | None` (new IR helper, used by layer methods and unit objectives).
  It returns the `(module address, call index)` whose **output** is this op:
  1. If `op["module"]` is set, return the innermost call in `op["modules"]` whose `strip_call` equals it
     (`"layer1.0.relu:2"` → `("layer1.0.relu", 2)`).
  2. Otherwise walk `op["modules"]` from innermost to outermost. Return the first call `c` for which this op is
     the last op of `_ops_in_call(ir)[c]` that has a child outside `c`. This covers BatchNorm (module is null) and
     collapsed module nodes, whose `output_op` is the block's last op.
  3. Otherwise return `None`.
- `module_calls(ir, address) -> int` (new): the number of distinct calls of that module address across all ops.

### 1.4 `attribution.py`

```python
METHODS = {"gxa": "Gradient x input", "saliency": "Saliency |grad|", "ig": "Integrated gradients"}   # unchanged
LAYER_METHODS = {"layer_ig": "Layer integrated gradients", "layer_cond": "Layer conductance"}
NEURON_LABEL = "Neuron conductance (Σ over positions)"
MERGE_METHOD = "Gradient x input at merge inputs"

def objective_forward(model, site: tuple[str, int] | None, channel: int | None) -> tuple[Callable, int | None]:
    """(fwd, target) for Captum. site None → (to_logits(model(x)), caller's target).
    Otherwise a forward hook on model.get_submodule(address) keeps the call-th output of each forward pass
    and fwd(x) returns out[:, channel].reshape(B, -1).sum(1, keepdim=True) → (B, 1); target 0.
    The hook is registered inside fwd and removed in a finally block (never left on the model)."""

def input_attribution(model, x, target, method, steps, fwd=None, progress=None) -> dict
    # as today; fwd defaults to logits. IG: wraps fwd to call progress((i + 1) / n, f"IG batch {i + 1}/{n}")
    # with n = ceil(steps / internal_batch_size); the wrapper raising Cancelled aborts Captum cleanly.

def attribute(model, inputs, method="ig", target=None, steps=32, categories=None, unit_ops=None,
              objective=None, site=None, progress=None) -> dict
    # objective {"op", "channel"} + site (resolved by runs.py); target ignored when objective is set.

def layer_attribution(model, x, layer: nn.Module, method, fwd, target, steps, progress=None) -> dict
    # Captum LayerIntegratedGradients | LayerConductance, baselines zeros, internal_batch_size min(steps, 16),
    # return_convergence_delta=True. attr[0] → per-channel: flatten(1).sum(1) for rank ≥ 2, the vector itself for rank 1.
    # returns {"channels": [...], "top": 12 by |v| [{channel, value}], "total": Σ, "convergence_delta": max |δ|}

def channel_conductance(model, x, layer: nn.Module, channel: int, fwd, target, steps, progress=None) -> torch.Tensor
    # raw (same shape as x) Σ_{j in channel} neuron conductance, baseline 0, riemann midpoints α_k = (k + ½)/steps:
    #   for each batch of α: xs = α·x (requires_grad); a hook keeps y = layer output;
    #   F = fwd(xs)[:, target]; gF = autograd.grad(F.sum(), y, retain_graph=True)[0].detach();
    #   s = (gF[:, channel] * y[:, channel]).sum(); acc += autograd.grad(s, xs)[0].sum(0)
    #   return x * acc / steps

def agreement(vectors: dict[str, np.ndarray], labels: dict[str, str], basis: str, k_frac=0.1) -> dict
    # ranks by |value|. n = common length, k = max(1, ceil(k_frac · n)).
    # jaccard[i][j] = |T_i ∩ T_j| / |T_i ∪ T_j|, overlap[i][j] = |T_i ∩ T_j| / k (T = top-k indices, stable argsort),
    # spearman[i][j] = Pearson of average ranks (ties averaged), None when either vector is constant.
    # returns {"basis", "methods", "labels", "n", "k", "jaccard", "overlap", "spearman"} (full symmetric matrices, diag 1)
```

The `attribute()` result is extended. The old fields keep their meaning; new or changed fields are marked:

```jsonc
{
  "method": "ig", "method_label": "Integrated gradients", "node_method": "Gradient x activation",
  "merge_method": "Gradient x input at merge inputs",                        // new
  "objective": {"kind": "logit", "index": 207} | {"kind": "unit", "op": "relu_2_4", "channel": 3},   // new
  "objective_label": "logit[207] · golden retriever" | "layer1.0.relu · ch 3 · Σ spatial",           // new (runs.py fills the path)
  "target": 207 | null,        // null for a unit objective
  "target_label": "golden retriever" | null,
  "prob": 0.83 | null,         // null for a unit objective
  "logit": 12.3 | null,        // null for a unit objective
  "value": 12.3,               // new: the objective scalar (logit, or Σ spatial activation of the unit)
  "steps": 32 | null, "input": {"map", "total", "convergence_delta"} | null,
  "scores": {op: float}, "merges": {child_op: {parent_op: float}},        // merges new
  "top_units": [{"op", "channel", "value", "path"}]
}
```

### 1.5 `runs.py`

- `RunManager.__init__` adds `self.jobs = JobRunner()`.
- Objective keys: `okey(target, objective)` is `"top"`, `"<int>"`, or `f"u_{safe_name(op)}_c{channel}"`.
- `attribution(run_id, method, target, steps, objective=None, progress=None)`:
  - Cache: `attribution/{method}_{okey}_{steps}.json`. A cached file without `"merges"` is stale, so recompute
    and overwrite it.
  - For a unit objective, resolve the site with `graph.module_site(ir, op)`. When it is `None`, raise
    `ValueError(f"{op} is not the output of a module; pick its module node (unit objectives hook module outputs)")`.
  - Fill `objective_label` and top-unit `path`, as `where` does today.
  - Also write `attribution/channels_{okey}.json` = `channel_scores`. The agreement units block reads it. It is
    never returned to the browser.
- `layer(run_id, method, op, target, steps, objective=None, progress=None)`:
  - Cache: `attribution/{method}_{okey}_{safe(op)}_{steps}.json`.
  - Site from `module_site`. With `None`, raise the same ValueError. When `module_calls(ir, address) > 1`, raise
    `ValueError(f"{address} is called {n} times; layer methods need a module called once")`.
  - Result: `{"method", "method_label", "op", "path": address, "objective_label", "steps", **layer_attribution(...)}`.
- `neuron(run_id, op, channel, target, steps, objective=None, progress=None)`:
  - Cache: `attribution/neuron_{okey}_{safe(op)}_c{channel}_{steps}.json`. Same site rules as `layer`.
  - Result: `{"method": "neuron_cond", "method_label": NEURON_LABEL, "op", "path", "channel", "objective_label",
    "steps", "input": {"map", "total", "convergence_delta": None}}`. The map is pooled and normalised exactly
    like `input_attribution`; share the helper.
- `agreement(run_id, target, steps, objective=None, op=None, progress=None)`:
  - Cache: `attribution/agreement_{okey}_{steps}[_{safe(op)}].json`.
  - Run or reuse the three input methods through `self.attribution`, each mapped into a sub-range of the
    progress. Input block: `agreement({m: np.asarray(res["input"]["map"])}, METHODS, "|attribution| · 24×24 pooled input map")`.
    It is `None` when there is no input map.
  - Units block, only when `op` is given: `gxa` = `channels_{okey}.json[op]`, plus `layer_ig` and `layer_cond`
    via `self.layer`. A method that raises is left out, and its message goes to `units_error`. The block is
    `agreement(...)` over the available methods (≥ 2), with basis `f"|attribution| · per channel of {path}"` and
    `op` added, else `None`.
  - Result: `{"objective_label", "steps", "input", "units", "units_error"}`.
  - Never hold `_lock` while calling the other methods.
- `patch(run_id, op, baseline, source_run=None, target=None, progress=None)`:
  - Cache: `patch/{safe(op)}_{baseline}[_{source_run}]_{target|top}.json`.
  - Replacement:
    - `zeros`: `zeros_like`.
    - `mean`: the mean over dims ≥ 2 (keepdim, expanded) for rank ≥ 3, over dim 1 for rank 2.
    - `run`: `store.load_tensor(source_run, op)` as a tensor on the out's device and dtype. The source must exist
      and have `meta.model.spec` equal and non-null, else
      `ValueError("source run must be a different run with the same model spec and weights")`. A shape mismatch raises
      `ValueError`.
  - Clean `before` logits come from a no-grad forward of the live model, which gives the clean top prediction.
    `target=None` means that argmax.
  - Result:
    ```jsonc
    {"op", "path": module_site address or op id, "baseline", "source_run",
     "method_label": "Activation patching · TorchLens replay",
     "target": 207, "target_label": str | null,
     "before": {"logit", "prob"}, "after": {"logit", "prob"}, "delta_logit", "delta_prob",
     "top_after": [TopK × 5],                      // same shape as meta.output
     "deltas": {op: float}, "rel": {op: float}}
    ```
- `job(run_id, req: dict) -> Job`: the one dispatcher the API calls.
  - Validate the required fields per kind. Raise `ValueError`, which the API turns into a 400:
    - `layer` needs `op` and `method in LAYER_METHODS`;
    - `neuron` needs `op` and `channel`;
    - `patch` needs `op`, and `source_run` when `baseline == "run"`;
    - `attribution` needs `method in METHODS`.
  - When the cache file for the request exists and is not stale, return `self.jobs.finished(kind, cached, run_id)`.
  - Otherwise return `self.jobs.submit(kind, lambda p: <method>(..., progress=p), run_id, key=<cache name>)`.
  - Progress messages: `"Node gradients"`, `"IG batch i/n"`, `"Layer IG batch i/n"`, `"Conductance batch i/n"`,
    `"Agreement · <method> (i/N)"`, `"Clean pass"`, `"Patched replay"`. The fraction is monotone and clamped to
    `≤ 0.99` until done.

### 1.6 HTTP API (`api.py`)

| Method | Path | Notes |
|---|---|---|
| POST | `/api/runs/{id}/jobs` | body `JobRequest` below → Job JSON. 404 unknown run; 400 when `manager.job` raises `ValueError`; 422 bad kind or field types |
| GET | `/api/jobs/{job_id}` | Job JSON; 404 unknown |
| POST | `/api/jobs/{job_id}/cancel` | Job JSON after the cancel request; 404 unknown |
| GET | `/api/jobs/{job_id}/events` | `text/event-stream`, see below; 404 unknown |
| GET | `/api/runs/{id}/graph` | adds `obj_op`, `obj_ch` (both or neither); forwards `objective` and `merges`, and `start=obj_op` to `graph_view` |
| POST | `/api/runs/{id}/attribution` | kept (synchronous); body gains optional `objective: {op, channel}`; `ValueError` → 400 |

```python
class Objective(BaseModel):
    op: str
    channel: int = Field(ge=0)

class JobRequest(BaseModel):
    kind: Literal["attribution", "layer", "neuron", "agreement", "patch"]
    method: str | None = None         # attribution: gxa|saliency|ig (default "ig"); layer: layer_ig|layer_cond (default "layer_ig")
    target: int | None = None
    objective: Objective | None = None
    steps: int = Field(32, ge=1, le=512)
    op: str | None = None             # layer / neuron / patch; agreement: optional (units block)
    channel: int | None = Field(None, ge=0)                     # neuron
    baseline: Literal["zeros", "mean", "run"] = "zeros"        # patch
    source_run: str | None = None                               # patch, baseline == "run"
```

Job JSON: `{"id", "kind", "run_id", "status", "progress", "message", "result", "error", "created"}`. `result` is
the kind's result from §1.4 / §1.5 once `status == "done"`, and `null` before that.

SSE: `StreamingResponse(gen(), media_type="text/event-stream", headers={"Cache-Control": "no-cache", "X-Accel-Buffering": "no"})`.
The sync generator loops on `jobs.wait(id, v, 15.0)`. On each change it yields `data: <job json>\n\n`. After a
timeout with no change it yields `: ping\n\n`. It returns after yielding a terminal state. The first event is sent
immediately (the initial `v = -1`).

### 1.9 Backend tests

`backend/tests/test_attr_m3.py` (new; `from test_pipeline import Tiny, Block`; module-scoped `captured` fixture as
in `test_graph_m1.py`):

1. **Merges on Tiny.** `op_gradients` gives `merges[add_op]` with both parents. The contributions sum to
   `scores[add_op]` (rel 1e-4). `graph_view(ir, 3, scores, merges=merges)`: the add node's incoming edges have
   `share_method == "merge"` and `share == |c_p| / Σ|c|` for each parent. `graph_view(ir, 3, scores)` without
   merges gives `share_method == "parent"` and the M2 values.
2. **Merges on ResNet-18** (random weights, 64×64): every `iadd`'s contributions sum to its score (rel 1e-3), and
   at least one merge share differs from the legacy share by > 0.05.
3. **Cat.** A small model `cat([conv_a(x), conv_b(x)], 1)` with `conv_b` weights and bias zeroed: the `conv_b`
   edge into `cat` has share 0 and `conv_a` has share 1.
4. **Unit objective.** `manager.attribution(run, "gxa", None, 8, objective={"op": relu_2_4, "channel": 3})`:
   - `value` equals the saved tensor's `[0, 3].sum()` (1e-4), and `prob`/`target` are None;
   - ops after the unit have no score;
   - the cache file name contains `u_relu_2_4_c3`;
   - `graph_view(..., start=op)["path"][0]` is the node holding that op.
   - IG on the same objective returns a `convergence_delta`.
   - A function op without a module (Tiny's `add`) raises `ValueError("… not the output of a module …")`.
5. **Layer methods.** `layer_ig` on `block.conv1` gives 8 channels and
   `|total − (F(x) − F(0))| ≤ convergence_delta + 1e-4`, with a label. `layer_cond` returns 8 channels.
   `block.relu` (called twice) raises "called 2 times". `module_site` resolves BatchNorm and collapsed-module
   output ops.
6. **Neuron conductance.** `channel_conductance` on Tiny's `fc` (rank-2 output), `channel=c`, `steps=8` equals
   Captum `NeuronConductance(fwd, model.fc).attribute(x, neuron_selector=c, target=t, n_steps=8, method="riemann_middle")`
   (atol 1e-5). The `neuron` result has a 16×16 map.
7. **Agreement function.** Identical vectors give all-1 matrices. Reversed ranks give Spearman −1. Disjoint top-k
   gives Jaccard 0. A constant vector gives Spearman `None`. Ties use average ranks (a hand-checked 4-element case).
8. **Agreement job on Tiny.** The input block is 3×3, symmetric, with diagonal 1. With `op=block.conv1` output,
   the units block has ≥ 2 methods and `n == 8`.
9. **IG progress.** `manager.attribution(..., "ig", None, 32, progress=cb)` records `"IG batch 1/2"` and
   `"IG batch 2/2"`, and the fractions are monotone.
10. **Patch zeros.** On Tiny's `conv2d` inside the block:
    - upstream deltas are 0;
    - the patched op's `rel == 1`;
    - downstream deltas are > 0;
    - `logits_after` equals a `register_forward_hook` zero replacement on that module (atol 1e-5).
    `mean` baseline: the patched op's after-tensor equals the spatial mean.
11. **Patch from a run.** Two spec runs `py:test_pipeline:Tiny` with different seeds; patching an op from the
    source equals the hook computation with the source tensor. A source run with a different spec gives a job
    error. A second identical request comes back `done` immediately.

`backend/tests/test_jobs_m3.py` (new):

   is monotone. An exception gives `error` with its message. Cancelling a queued job (queue it behind a blocking
   job) gives `cancelled` without it ever running. Cancelling a running job (fn loops on `progress` with a small
