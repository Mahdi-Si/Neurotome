# v0.2 · Sequences and LLMs: implementation spec

Status: ready to build · Covers PLAN.md §8 v0.2 (six items) · Read with ARCHITECTURE.md, DESIGN.md and the M1–M4
specs. Their conventions still apply: URL hash state, pure `*State.ts` helpers with vitest tests, backend tests in
`backend/tests/test_*_v02.py`, old runs must still open (every new IR/meta field is optional and read with `.get`).

**Hard rule: never publish.** No push, no PyPI, no docs deploy. Tests never touch the network: tiny HF models are
built from configs (or saved to `tmp_path` and loaded back); only the Integrate live smoke (§9) downloads models.

## 0. Current flow and verified facts

```
HomeView form ─ POST /api/runs {model, weights, sample:{kind: random|upload}} ─▶ capture job
  load_model(spec) → build_input (image / .npy / .pt / randn) → capture.capture (TorchLens) → meta.json, ir.json
Tensor view: GET …/tensor → tensors.tensor_view → image | sequence | vector
Trace view:  job "attribution" → attribution.attribute → op_gradients (TorchLens) + Captum on a float input;
             integer input → input: null + input_note ("planned for v0.2")
```

Verified in `.venv` while writing this (torch 2.14, torchlens 2.34.1, captum 0.9.0, transformers 5.17.0,
nnsight 0.7.0; the implementers still declare them in `pyproject.toml`):

| Fact | Consequence |
|---|---|
| `GPT2LMHeadModel(cfg)` / `LlamaForCausalLM(cfg)` (2 layers, 32 dims, vocab 64) trace with TorchLens in <1 s on `randint(0, 64, (1, 7))`; the input op is `int64` | integer inputs already flow through capture; no capture change needed for tokens |
| With `use_cache=True` the trace has **5 output ops** (logits + KV cache); with `model.config.use_cache = False` exactly one `(1, T, V)` | loaders **must** set `config.use_cache = False` |
| `attn_implementation` is not a model `__init__` kwarg; `model.set_attn_implementation("eager")` works on a built model, `from_pretrained(..., attn_implementation="eager")` on a loaded one | eager everywhere, so softmax ops exist |
| eager attention: one `softmax` op per layer, shape `(1, H, T, T)`, module stack ends in `transformer.h.0.attn:1` / `model.layers.0.self_attn:1`, `module: null` (functional) | detect attention numerically (§3), not by module |
| embeddings: `embedding` ops with `module` `transformer.wte` / `model.embed_tokens`; `model.get_input_embeddings()` returns it | LIG layer |
| `RunManager.create_from_objects(tiny_gpt2, ids)` works today: top-k OK, 123/125 ops saved, node scores OK, `input: null` + note | only the input map is missing |
| `LayerIntegratedGradients(lambda ids: m(ids).logits[:, -1], m.transformer.wte)` with token-id baselines: `(1, T, D)`, convergence Δ ≈ 3e-8 | baselines are **token ids** (a pad-token embedding), not a zero vector |
| nnsight 0.7: `with NNsight(model).trace(x) as tr: cache = tr.cache()` gives `CacheDict` keyed `"model.<address>"` (root = `"model"`), value an `Entry` (`.output`, `.inputs`) or a **list of Entries for a module called more than once**, in call order | module outputs per call without ordering rules |
| nnsight 0.7: reading `envoy.output` inside a trace must follow execution order (`OutOfOrderError` / `MissedProviderError` otherwise) | do **not** read `.output` per module; use `tr.cache()` |
| plain forward (pre-)hooks on the same modules give call order, the call stack and input `data_ptr`s; input `data_ptr`s match the producer's output `data_ptr` | module-call graph edges by tensor identity |

## 2. Hugging Face models and token input (items 1, 2)

### 2.1 `models.py`

- `check_spec` accepts `hf:` (`Use 'torchvision:<name>', 'hf:<repo_id>' or 'py:<module>:<factory>'`).
- `LoadedModel` gains `tokenizer: Any | None = None` and `lm: bool = False`. `categories` may be a `Vocab`.
- `class Vocab(Sequence[str])`: `__init__(tokenizer, size)`, `__len__` = size, `__getitem__(i)` =
  `tokenizer.decode([i])` (ints only). Used for LM categories so `_top_of` / `logit_label` label tokens lazily.
- **Tokenizer protocol** (all Neurotome needs): `encode(text) -> list[int]`, `decode(list[int]) -> str`, optional
  `pad_token_id`, `eos_token_id`. HF tokenizers satisfy it.
- `_prepare_hf(model) -> model`: `model.set_attn_implementation("eager")` when it has it (ignore failures),
  `model.config.use_cache = False`, `.eval()`. Called for every `PreTrainedModel` (hf: and py: specs).
- `is_lm(model)`: `type(model).__name__.endswith(("ForCausalLM", "LMHeadModel"))`.
- `_load_hf(repo, weights, device)`:
  - `import transformers` inside; `ImportError` → `ValueError("Hugging Face models need the hf extra: pip install
    'neurotome[hf]'")`.
  - `config = AutoConfig.from_pretrained(repo)`; class = `getattr(transformers, config.architectures[0])` when that
    exists, else `AutoModel`. (gpt2 → `GPT2LMHeadModel`, Qwen → `Qwen2ForCausalLM`, bert-base-uncased →
    `BertForMaskedLM`, ViT → `ViTForImageClassification`.)
  - `weights` falsy (random init, still seeded by `load_model`): `cls._from_config(config, attn_implementation="eager",
    dtype=torch.float32)`; else `cls.from_pretrained(repo, attn_implementation="eager", dtype=torch.float32)`.
    Then `_prepare_hf`, `.to(device)`.
    `# ponytail: float32 only; bf16 / device_map for >16 GB models belongs to v0.4 (Scale)`.
  - Text models: `AutoTokenizer.from_pretrained(repo)` succeeds → `tokenizer`, `categories = Vocab(tok, V)` with
    `V = model.get_output_embeddings().out_features` (fallback `config.vocab_size`), `default_input_shape = [1, 16]`,
    `preprocess = None`, `lm = is_lm(model)`.
  - Image models (`AutoImageProcessor.from_pretrained` works and no tokenizer): `preprocess = lambda img:
    proc(images=img.convert("RGB"), return_tensors="pt")["pixel_values"]`, `norm = (proc.image_mean,
    proc.image_std)`, `default_input_shape = [1, 3, S, S]` (`S = config.image_size`, default 224),
    `categories = [config.id2label[i] for i in range(len(id2label))]` when `id2label` is non-trivial.
  - `spec = f"hf:{repo}"`. A local directory works as `repo` (tests use `hf:<tmp_path>`).
- `_load_python`: when the factory returns a `transformers.PreTrainedModel` (check via
  `type(m).__mro__` class names containing `PreTrainedModel`, so no import is needed), apply `_prepare_hf`. A module may
  define `TOKENIZER` (object with the protocol) → `tokenizer`, `categories = Vocab(...)`, `lm = is_lm(model)`,
  `default_input_shape = [1, 16]` unless `INPUT_SHAPE` is given.
- `SUGGESTED_MODELS` += `hf:gpt2`, `hf:Qwen/Qwen2.5-0.5B`, `hf:google/vit-base-patch16-224`;
  `TEXT_MODELS = ["hf:gpt2", "hf:Qwen/Qwen2.5-0.5B"]`.
- `to_logits` is unchanged (ModelOutput `.logits`, (B, T, V) → last position). A masked LM (BERT) explains its last
  position; documented, not special-cased.

## 3. Attention-pattern viewer (item 3)

### 3.1 `tensors.py`

After `_drop_batch` and the rank > 3 fold: `if _is_attention(a): return _attention_view(a, shape, channel)`, before
the image branch.

`_is_attention(a)`: `a.ndim == 3`, `a.shape[1] == a.shape[2] > 1`, all finite, `min ≥ -1e-6`, `max ≤ 1 + 1e-6`,
and every row sums to 1 within `1e-3` (`np.abs(a.sum(-1) - 1).max()`). This covers softmax outputs inside attention
modules (causal masks keep rows normalised) and NNsight's `attn_dropout` outputs; a pre-softmax score tensor or an
unnormalised `(C, H, H)` feature map stays `image`.

`_attention_view(a, shape, head)` (`a` is `(H, T, T)`, query rows × key columns):
- `head` = `channel` clamped to `[0, H)`, default 0.
- `maps`: for the first 64 heads, `g = pool2d(a[h], 64, 64)`, `max = g.max()`, `map = _r(g / max, 2)` (zeros when
  max is 0).
- `full`: `pool2d(a[head], 128, 128)`, same scaling, 3 decimals.
- `summary` per head from the unpooled map: `entropy = mean_q(-Σ_k p log2 p)` (0 log 0 = 0); `prev =
  mean_{q≥1} a[q, q-1]`; `first = mean_q a[q, 0]`; `self = mean_q a[q, q]`; `pattern` = the name of the one of
  (`previous`, `first`, `self`) above 0.5 (first match in that order), else null.
- `stats` over the whole tensor; `hist = _hist(a[head])`. `tokens = T`, `heads = H`.

### 3.2 Frontend (`AttentionBody` in `views/TensorView.tsx`)

- Axis boxes read `B H Q K` for a `(1, H, T, T)` shape; the `H` box is hot (accent) like `C` for images.
- Left rail: `Head (0–H-1)` number field (writes `c`), the stats kv block (`Scope · head h`).
- **Main** (`h1` `Attention`, dim right `H heads · T tokens · each map scaled to its max`): a grid of head tiles
  like the channel grid (`HeatCanvas`, sequential ramp; selected tile 2 px `accent` border), label `h{h}` +
  dim `{entropy} b` + the `pattern` word (`prev` / `first` / `self`) in `accent`. Click selects the head (`c`).
  Below: the **Head summary** table (`<table aria-label="Head summary">`, `.num` cells, `line-soft` rules,
  columns `Head · Entropy (bits) · Prev · First · Self · Pattern`, selected row `accent-soft`, click selects).
  Then the values table (free, as for every kind).
- **Side** (420 px): big `h{head}` number + dim `T×T → n×n pooled`; the selected head's `full` map as a square
  `HeatCanvas` labelled `Head {h} attention` with a readout
  `q {spanLabel(row)} → k {spanLabel(col)} · {unscaled weight, 3 decimals}` (unscaled = `v × full.max`; pooled cells
  say `mean`), a crosshair on click (`mark`, local state). For `T ≤ 32`, token tick labels on both axes (left column
  for queries, a rotated −60° top row for keys; mono 10.5 px `ink-2`). Upper-triangle zeros of a causal map are
  simply `paper`. Then `Value distribution` for the head.
- Pure helpers in `lib/attentionState.ts` (with `attentionState.test.ts`): `headReadout(t, r, c, v, tokens)`,
  `patternLabel(p)`, `axisLetters(shape, kind)`.

## 4. Logit lens (item 4)

### 4.1 `lens.py` (new; backend, no TorchLens)

```python
BLOCKS = ("transformer.h", "model.layers", "gpt_neox.layers", "model.decoder.layers", "transformer.layers")
NORMS = ("transformer.ln_f", "model.norm", "gpt_neox.final_layer_norm", "model.final_layernorm",
         "model.decoder.final_layer_norm", "transformer.norm_f")
def lens_parts(model) -> tuple[list[tuple[str, nn.Module]], tuple[str, nn.Module], tuple[str, nn.Module]]:
    """(blocks, (norm_path, norm), (head_path, head)); ValueError(UNSUPPORTED) when any is missing."""
def logit_lens(model, x, target: int | None, tokenizer, k=5, max_positions=64, progress=None) -> dict: ...
```

- blocks: the first of `BLOCKS` that is an `nn.ModuleList`; norm: the first of `NORMS` that exists; head:
  `model.get_output_embeddings()` (path found by identity in `named_modules`). GPT-2, Llama, Qwen2, Mistral,
  Phi-3 (`model.layers` + `model.norm`), Phi-2 (`model.final_layernorm`), GPT-NeoX (`embed_out`) are covered.
- `UNSUPPORTED = f"Logit lens needs a causal LM whose final norm and unembedding it can find (GPT-2, Llama, Qwen,
  Mistral, GPT-NeoX, Phi); {type(model).__name__} is not supported."`
- One forward pass under `torch.no_grad()` with a `register_forward_pre_hook(with_kwargs=True)` on block 0 keeping
  `args[0] if args else kwargs["hidden_states"]` (row `embed`) and a forward hook per block keeping its first tensor
  output (`capture._first_tensor`, for tuple outputs). Hooks removed in `finally`.
- Per row: `logits = head(norm(resid))[0, pos0:].float()`, `p = softmax`, top-k ids/probs, `target` (None → argmax of
  the model's own last-position logits) prob and rank (`(p > p[target]).sum() + 1`). Positions: the last
  `max_positions` (`pos0 = max(0, T - 64)`). Token text: `tokenizer.decode([id])` (no tokenizer → `str(id)`).
- Invariant (tested): the last block's row equals `softmax(model(x).logits[0, pos0:])` (atol 1e-4) for GPT-2 and
  Llama, since HF applies exactly that norm then head.
- Progress: `Lens forward` (0.1), `Project layer i/L`.
- Result (`LensResult`, §1.4), `method_label = f"Logit lens · {norm_path} + {head_path}"`, 4-decimal probs.

## 6. NNsight capture backend (item 6)

### 6.1 `capture_nnsight.py` (new; the only NNsight-aware file)

Same contract as `capture.py`:

```python
MISSING = "The nnsight backend needs the nnsight extra: pip install 'neurotome[nnsight]'"
PATCH = ("Activation patching replays TorchLens ops; this run was captured with NNsight (module outputs only). "
         "Capture it again with the TorchLens backend to patch.")
def available() -> bool                                   # importlib.util.find_spec("nnsight") is not None
def capture(model, inputs, store, run_id, max_bytes=None, modules=None, progress=None) -> dict   # IR
def op_gradients(model, inputs, target, to_logits, objective=None) -> dict   # same keys as capture.op_gradients
def patch(*_a, **_k): raise ValueError(PATCH)
```

- **Ops = leaf-module calls** (modules without children), in execution order, plus `input` and `output` ops. Id:
  `f"{address}@{call}"` (`transformer.h.0.mlp.c_fc@1`, `block.relu@2`); input `input_1`, output `output_1`.
- **Structure from hooks** registered on every named module for the duration of the trace (removed in `finally`):
  a forward pre-hook (`with_kwargs=True`) pushes `(address, call)` on a stack and records the `data_ptr`s of the
  tensors in `args` / `kwargs` (one level into tuples/lists); a forward hook pops it and, for leaf modules, appends
  `(address, call, stack_calls, input_ptrs, output_ptr)`. `modules` of an op = `[f"{a}:{c}"` for every call on the
  stack (outermost first, root excluded)] + its own call — the same shape as TorchLens's stack, so `graph_view`,
  `module_site(s)`, layer methods and unit objectives work unchanged.
- **Values from NNsight**: `with NNsight(model).trace(*args) as tr: cache = tr.cache(modules=[leaf paths inside the
  selection, or every leaf])` (paths `"model." + address`); the k-th call's tensor is `entry.output` or
  `entries[k-1].output` for a list; `_first_tensor` of it. The model output is kept via `tr` / `model.output.save()`
  (`.logits` when present). A call count mismatch between hooks and cache → `TraceError`. Import `nnsight` inside;
  missing → `ValueError(MISSING)`. Other failures → `TraceError("NNsight could not trace forward(): …")` like
  `capture._trace_or_raise`.
  `# ponytail: the cache holds every leaf output on CPU until saved; stream per module when models outgrow RAM`.
- **Edges by tensor identity**: `producer[data_ptr] = op id` (the input op's tensor first, then each leaf call's
  output in order). A leaf call's parents = the producers of its input pointers (deduped, order kept); none found
  (the input came from a functional op between modules, e.g. a residual add) → the previous leaf call. The output
  op's parent = the producer of the output tensor, else the last leaf call. `children` are the inverse.
- Op fields: `type = type(module).__name__.lower()`, `func: null`, `flops: 0`, `num_params` = own parameters
  (`recurse=False`), `module = address`, `dtype`/`device`/`shape` from the tensor; budget, `modules` selection
  (`_check_modules`), `unsaved`, `stats` and progress (`Trace`, `Save tensors i/N`) exactly as `capture.capture`
  (reuse `tensor_stats`, `_check_modules`, `_first_tensor`, `_module_table`-equivalent from hooks: `{address:
  {class_name, num_params (recursive), depth: address.count(".") + 1}}`).
- IR `model` = the TorchLens block with `flops: 0`, `num_ops` = leaf calls, `"backend": "nnsight"`,
  `"granularity": "module"`.
- `op_gradients`: plain autograd at the same granularity: the same hooks (so ids match) call `retain_grad()` on each
  leaf call's output; forward, back-propagate `logits[0, target]` (or the unit `out[0, c].sum()` of the op named by
  `objective["op"]`), `NO_GRAD` check as in `capture.op_gradients`; `scores` / `channel_scores` per op id, `merges:
  {}` (so the graph uses parent shares, labelled `share_method: parent`). Float inputs get `_grad_leaf`.

`capture.py` changes only by adding `"backend": "torchlens", "granularity": "op"` to its IR `model` block.

### 6.2 Attention at module level

GPT-2's eager attention runs `attn_dropout` (a leaf `Dropout`) on the probabilities, so its `(1, H, T, T)` output
opens as `attention`. Llama/Qwen apply dropout functionally: no module holds the probabilities, so NNsight runs
have no attention views for them (documented trade-off).

### 6.3 Backend selection (`runs.py`)

- `RunManager(..., nnsight_params: int = 1_000_000_000)`; `config.py`: `NEUROTOME_NNSIGHT_PARAMS` → `Settings.nnsight_params`.
- `_create(..., backend: str | None)`: explicit `"nnsight"` without the package → `ValueError(MISSING)`;
  `None` (auto) → `"nnsight"` when `num_params > nnsight_params` and `available()`, else `"torchlens"`. When auto
  picks nnsight the capture job reports `Large model ({n/1e9:.1f} B params) · NNsight module capture`.
- `_backend(run_id)`: the module named by `meta.model.backend` (default torchlens), imported lazily; attribution
  passes its `op_gradients`, `patch` calls its `patch` (NNsight → 400 `PATCH`).
- `api.CreateRun.backend`, `start_capture(..., backend)`, CLI `--backend`, `create_from_objects(..., backend)`.

### 6.4 Docs (ARCHITECTURE.md): the trade-off

| | TorchLens (default) | NNsight (`backend: nnsight`, auto above 1 B params) |
|---|---|---|
| Graph | every op, including functional ones (`add`, `softmax`, `view`) | leaf-module calls; functional ops between modules are invisible and edges fall back to call order |
| Attention maps | every softmax | only where a module outputs the probabilities (GPT-2 `attn_dropout`) |
| Merge shares | exact grad × input through merges | parent shares (approximate, labelled) |
| Patching | yes (DAG replay) | no (400) |
| Cost | records every op (memory and time grow with op count) | hooks + one cache per leaf; much smaller IR |
