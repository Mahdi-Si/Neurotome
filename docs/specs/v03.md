## 0. Current flow and verified facts

```
Graph inspector PatchPanel ─ job "patch" {op, baseline zeros|mean|run, source_run} ─▶ RunManager.patch
  → capture.patch: tl.trace(intervention_ready) + trace.do(label, replace_with, engine="replay") → deltas/rel
  → GraphView colour "Patch Δ" (URL patch/pb/psrc); NNsight runs: 400 PATCH
```

Verified in `.venv` while writing this (torch 2.14, torchlens 2.34.1, nnsight 0.7.0, transformers 5.17):

| Fact | Consequence |
|---|---|
| **TorchLens DAG replay does not propagate through multi-pass ops.** Tiny GPT-2: TorchLens records a block's two residual adds as passes of one layer (`add_6_56.p1`, `add_6_56.p2`). `trace.do({label: hook}, engine="replay")` on `dropout_4_72` changes only that op; nothing downstream is recomputed (logits off by 0.1 vs a forward hook). Scaling `add_6_56.p1` changes nothing; `ln_f` replay raises `IndexError` | M3's replay patch is silently wrong on HF LMs. v0.3 drops replay |
| **Capture-time interventions work.** `tl.trace(model, x, layers_to_save="all", unwrap_when_done=True, intervene=pick)`, where `pick(ctx)` returns `hook` when `ctx.raw_index == op.raw_index` (`op.raw_index` read from a clean trace of the same input) and `def hook(out, *, hook): return new` (`hook` must be keyword-only). Matches forward hooks exactly on Tiny `conv2d_3_5`, GPT-2 `add_6_56.p2` (block 0 output), `layernorm_5_118` (`ln_f`), and on ResNet-18 with `out += identity` / `ReLU(inplace)` (zeroing `layer3.0.downsample.1`: logits equal, `relu_11_43` equals the block's hooked output, `iadd_5_42` recorded correctly, so no "lost" ops). The edited trace has the same op ids (`_id_maps`) as the clean one | TorchLens backend = clean trace + one edited trace. `ctx.raw_label` has a `_raw` suffix, so match on `raw_index` |
| Several edits in one trace compose in execution order (a downstream edit's hook receives the upstream-edited value). Also true for `trace.do({l1: h1, l2: h2})` | one pass for the whole set |
| An op that returns its input object (eval-mode `dropout`, GPT-2 `mlp.dropout` = `dropout_4_72`) fires the hook but TorchLens keeps the original value (recorded out unchanged, children unchanged) | detect after the trace (§2.3) and refuse with a message naming the parent op |
| A `ValueError` raised inside a TorchLens hook reaches the caller unchanged | edit functions may raise friendly errors |
| NNsight 0.7: `env.output = fn(env.output)` inside `with NNsight(model).trace(x) as tr:` edits a module call; the k-th call of a module in one forward is `with tr.iter[k - 1]: env.output = …` (verified on Tiny `block.relu` call 2 against a forward hook). Edits must be written in execution order. A plain `nnsight.Envoy.next()` or a second `.output` read does **not** reach call 2 | NNsight backend edits leaf calls natively |
| NNsight 0.7: forward hooks registered by `capture_nnsight._Recorder` see a module's output **before** NNsight's swap (edited call recorded unedited; its consumers see the edit) | after value of an edited call = `fn(recorded)` |
| NNsight silently skips a body whose variables are not returned via `.save()`; errors inside can be swallowed by `warnings` filters | tests compare against forward hooks, never trust a silent run |

## 1. Contracts (every package codes against these)

### 1.1 Intervention IR (the request body and `result.set`)

```jsonc
// InterventionSet
{ "target": null,                 // logit index reported as Δ (null = the clean run's top prediction)
  "edits": [                      // 1..32, applied in one forward pass; several edits on one op compose in list order
    { "op": "conv2d_3_5",         // IR op id (a graph node's output_op); not an input/output op; float dtype
      "kind": "zero" | "mean" | "resample" | "constant" | "scale" | "steer",
      "channels": null | [0, 3],  // null = every channel
      "positions": null | "last" | [2, 5] | [[4, 7], [4, 8]],   // null = every position (rules in §1.2)
      // kind parameters (only the ones of the kind are kept after normalisation):
      "over": "positions" | "runs",                         // mean; default "positions"
      "source_run": "run_0004" | "random",                  // resample (required); this run allowed (a no-op)
      "seed": 0,                                            // resample with "random"
      "value": 0.0,                                         // constant; default 0
      "alpha": 1.0,                                         // scale (×α), steer (+α·v); default 1
      "direction": {"kind": "contrast", "run_a": "run_0005", "run_b": "run_0006", "pool": "mean" | "last"}
                 | {"kind": "channel", "channel": 3} } ] }  // steer (required)
```

### 1.2 Scope axes (server and `scopeAxes()` agree)

The op's IR `shape` includes the batch axis. Every edit computes a full replacement `r = f(x)` (same shape) and writes
`out = where(mask, r, x)`; `mask` = channel mask ∧ position mask (null = all).

| Rank | Channel axis | Positions | Position format |
|---|---|---|---|
| 4 `(B, C, H, W)` (attention `(B, H, Q, K)` too) | 1 | `(H, W)` | `[[y, x], …]`, `0 ≤ y < H`, `0 ≤ x < W` |
| 3 `(B, T, D)` (the tensor view's `sequence`) | 2 (features) | `T` (tokens) | `[t, …]` or `"last"` (T − 1, re-resolved per step in generation) |
| 2 `(B, D)` | 1 | — | — |
| other | — | — | — (scope must be null/null) |

Kind semantics (`x` = the op's output as it arrives, after upstream edits):

| Kind | `r` |
|---|---|
| `zero` | 0 |
| `mean`, `over: positions` | per-channel mean over the positions axes, broadcast (rank 4: dims 2, 3; rank 3: dim 1 = the token mean; rank 2: dim 1; other ranks: dims ≥ 2, else the last) |
| `mean`, `over: runs` | element-wise mean of this op's saved tensor over every run with the same `model.spec` + `model.weights` and the same shape (this run included; ≥ 2 runs) — dataset-free: the runs on disk are the batch |
| `resample` | the op's saved tensor in `source_run` (same spec + weights + shape); `"random"` = `random.Random(seed).choice(sorted(candidates))` over the *other* runs that qualify. An explicit source is labelled `Replace`, random `Resample` |
| `constant` | `value` everywhere |
| `scale` | `alpha · x` |
| `steer` | `x + alpha · v`, `v` broadcast along the channel axis: `contrast` → `pool(act_B) − pool(act_A)` of this op's saved tensors in `run_b` / `run_a` (same spec + weights, same channel count; either may be this run), pooled over positions (`mean`, or `last` token for rank 3; rank 2 needs no pooling); `channel` → the unit vector `e_c`. Rank 2–4 only |

No-ops by construction: `scale` α = 1, `steer` α = 0, `resample` from this run (float32 storage of a float32 model).

### 1.3 Normalisation, hash and friendly errors (`interventions.normalise`, HTTP 400)

`normalise(raw, ir)` returns the canonical set: `target` int or null; per edit only the keys of its kind, defaults
filled (`over`, `seed` only with `random`, `value`, `alpha`, `direction.pool` only for `contrast`), `channels` /
position lists sorted and de-duplicated (`[]` → null). `hash = sha1(json.dumps(norm, sort_keys=True,
separators=(",", ":"))).hexdigest()[:12]`, so key order and list order never change it. Messages (substring-tested):

| Case | Message |
|---|---|
| no edits / > 32 | `An intervention set needs at least one edit` / `At most 32 edits per set` |
| op not in IR | `Unknown op {op}` |
| input / output op | `{op} is the model's input or output; pick an op inside the model` |
| non-float op | `{op} holds {dtype} values; only float tensors can be edited` |
| channels out of range | `Channel {c} out of range for {op} ({n} channels)` |
| scope on a rank without it | `{op} has shape {shape}: channel / position scopes need a (B, C, H, W), (B, T, D) or (B, D) tensor` · `{op} has no positions (shape {shape}); scope it by channels` |
| wrong position format / range | `Positions of {op} are [y, x] pixels (H {H}, W {W})` · `Positions of {op} are token indices below {T}` · `"last" applies to token positions (B, T, D)` |
| resample / mean runs / contrast source | `Resample needs source_run (a run id or "random")` · `Source run {id} not found` · `{id} is a run of another model ({spec} · {weights}); use a run with the same model spec and weights` · `{id} has no saved tensor for {op}` · `{id}'s {op} has shape {a}, this run's {b}` · `No other run of this model has a saved tensor for {op}` · `Mean over runs needs another saved run of this model with a tensor for {op}` |
| steer | `Steering needs a direction` · `Steering needs a (B, C, H, W), (B, T, D) or (B, D) tensor; {op} is {shape}` · `Direction channel {c} out of range for {op} ({n} channels)` · `Contrast runs have {a} and {b} channels at {op}` |
| TorchLens cannot edit the op (§2.3) | `TorchLens cannot edit {op} ({func}): it returns its input unchanged in eval mode. Edit its parent {parent} instead.` |
| target | `Target {t} is outside the output (0–{n-1})` |
| generate | `Generation needs a causal language model with a tokenizer; this run's model is not one.` · `Generation edits {op} through a forward hook on its module; {op} is not the output of a module (pick its module node)` · `Generation supports zero, mean over positions, constant, scale and steer edits ({kind} values have the prompt's length)` · `The prompt ({T} tokens) plus {n} new tokens exceeds the model's {P} positions` |

Pydantic types (422) cover the shapes; counts and ranges are the 400s above, so the UI always shows a sentence.
Everything that needs no model (normalise, source runs, saved tensors, shapes) is checked **when the job is
requested** (`RunManager.job`), so the POST answers 400; the TorchLens "cannot edit" and target checks run in the job.

### 1.4 Storage

```
runs/<id>/interventions/<hash>/meta.json               InterventionResult (below); rename rewrites "name" only
runs/<id>/interventions/<hash>/tensors/<op>.npy        intervened activations of saved downstream ops (float32)
runs/<id>/interventions/<hash>/generate_<n>.json       GenerationResult for n new tokens
```

`hash` is `[0-9a-f]{12}`; anything else is a 404 (the store raises `KeyError`). **Downstream** = the edited ops and
every IR descendant (via `children`), in IR order. **Saved** = the downstream ops that the clean run saved and that are
float, walked in IR order under the run's capture budget (`ir.model.budget_bytes`, else the server's
`max_capture_bytes`; `None` = unlimited) with the "never cross" rule: the first one whose `numel × 4` does not fit and
everything after it are skipped (`truncated: true`). A folder without `meta.json` (a generate-only set) is not listed.
Old runs have no `interventions/` folder: the list is `[]`. Deleting a run deletes its interventions.

```jsonc
// InterventionResult (meta.json; the intervene job's result; GET …/interventions/{hash})
{ "hash": "3f9a0c1d2e4b", "run_id": "run_0003",
  "name": "Zero · block.conv2 · all (+1)",   // default: first label, "(+n)" when more; PATCH renames
  "created": 1695480000.0,
  "set": { /* normalised InterventionSet */ },
  "labels": ["Zero · block.conv2 · all", "Scale ×3 · block.relu · ch 0–3"],   // one per edit, resolved (§1.5)
  "method_label": "Intervention · TorchLens capture-time hooks (every op)",   // NNsight: "Intervention · NNsight (module outputs)"
  "target": 3, "target_label": "cat",
  "before": {"logit": 12.31, "prob": 0.83}, "after": {"logit": 9.10, "prob": 0.12},
  "delta_logit": -3.21, "delta_prob": -0.71,
  "top_before": [/* TopK ×5 */], "top_after": [/* TopK ×5 */],
  "edited": ["conv2d_3_5", "relu_3_7"],              // distinct edited ops, IR order
  "downstream": ["conv2d_3_5", "add_1_6", …],         // IR order
  "saved": ["conv2d_3_5", "add_1_6"],                  // tensors on disk, a prefix of the eligible downstream ops
  "truncated": false, "budget_bytes": 2147483648, "bytes": 16384,
  "nodes": {"add_1_6": {"l2": 3.2, "rel": 0.41, "cos": 0.91, "max_abs": 0.77, "nonfinite": 0}},   // every downstream op with a float tensor
  "stats": {"add_1_6": {/* capture.tensor_stats of the intervened tensor */}} }   // same keys as nodes
```

Diff row (`nodes[op]`): over positions where both are finite, `l2 = ‖after − before‖₂`, `rel = l2 / ‖before‖`
(0 when ‖before‖ = 0), `cos` = cosine(before, after) (null when a norm is 0), `max_abs = max |after − before|`;
`nonfinite` = positions where either is NaN / inf and they differ. Non-finite logits / probs are served as null.
Ops outside `downstream` are unchanged by definition and have no row.

```jsonc
// InterventionSummary (GET …/interventions, newest first)
{ "hash", "name", "created", "labels", "target", "target_label", "delta_logit", "delta_prob", "truncated" }

// GenerationResult (generate job result; generate_<n>.json)
{ "hash": "3f9a0c1d2e4b", "n": 16, "labels": [...],
  "method_label": "Greedy decoding · 16 new tokens · edits as forward hooks on module outputs · no KV cache",
  "prompt": ["t", "h", "e"],                                  // decode([id]) per prompt id
  "clean":   {"ids": [...n], "tokens": [...n], "text": "…",   // text = decode(ids)
              "top": [[{"id": 3, "token": "c", "prob": 0.41}, … ×5] … ×n]},   // next-token top-5 at each step
  "steered": { /* same */ },
  "diverge": 3 }                                              // first step whose token differs; null = identical
```

### 1.5 Edit labels (server `labels`; the client's `editLabel` uses the same words for drafts)

`<Kind> · <path> · <scope>`; `path` = `module_site(ir, op)[0]` (with `@<call>` when call > 1), else the op id; scope
`all` | `ch 0,3,7–9` | `px (4,7) (4,8)` (at most 4 pairs, then `+n`) | `last token` | `tokens 2,5`; channel and position
parts join with ` · `. Kinds: `Zero`, `Mean over positions`, `Mean over <n> runs` (client draft: `Mean over runs`),
`Replace ← run_0004`, `Resample ← run_0004 (random · seed 0)` (client draft: `Resample ← random · seed 0`),
`Constant 0.5`, `Scale ×2`, `Steer +4 × (run_0006 − run_0005, last)` / `Steer +4 × e_3`. Runs of ≥ 3 consecutive
indices print as `a–b` (en dash). Numbers print with up to 3 significant decimals (`×0.5`, `+4`, `×1.25`).

### 1.7 Backend contract (both capture modules; ARCHITECTURE.md documents it)

```python
Edit = tuple[str, Callable[[torch.Tensor], torch.Tensor]]   # (op id, fn: the op's output -> same-shape tensor)

def intervene(model, inputs, edits: list[Edit], downstream: Collection[str], keep: Collection[str] = ()) -> dict:
    """One forward pass with every edit applied where its op runs; edits on one op compose in list order.
    Returns {"nodes": {op: diff row}, "stats": {op: tensor_stats(after)}   # downstream ops with a float tensor
             "after": {op: np.ndarray float32}                           # op in keep (CPU copies)
             "logits_after": the model output (anything models.to_logits accepts)}.
    ValueError: "Unknown op …", an fn that changes the shape ("Edit of {op} changed its shape {a} -> {b}"),
    an op the backend cannot edit (§1.3)."""
```

`capture.patch` and `capture_nnsight.patch` / `PATCH` are **deleted** (and `runs._spatial_mean`, which moves into
`interventions.py` as `mean over positions`). Edit functions come from `interventions.edit_fn` (pure torch); only the
capture modules decide *where* they run.

## 2. Backend (package A)

### 2.1 `interventions.py` (new; pure torch / numpy, no TorchLens, no NNsight)

```python
KINDS = ("zero", "mean", "resample", "constant", "scale", "steer"); MAX_EDITS = 32; MAX_NEW_TOKENS = 64
def normalise(raw: dict, ir: dict) -> dict            # §1.3 (IR-only checks; sources are checked by RunManager)
def set_hash(norm: dict) -> str
def downstream(ir: dict, ops: Iterable[str]) -> list[str]            # §1.4, IR order
def keep_ops(ir: dict, down: list[str], budget: int | None) -> tuple[list[str], bool]   # (saved, truncated)
def scope_mask(shape, channels, positions) -> torch.Tensor | None    # bool, broadcastable; "last" = T-1 of this shape
def edit_fn(edit: dict, value: np.ndarray | None) -> Callable[[torch.Tensor], torch.Tensor]
    # value: the resample / runs-mean replacement, or the steer direction v (channel-axis vector); converted with
    # torch.as_tensor(value, dtype=t.dtype, device=t.device) on first call; the mask is built from t.shape per call
def label(edit: dict, path: str, resolved: str | None = None, n_runs: int | None = None) -> str   # §1.5
def diff_row(before: np.ndarray, after: np.ndarray) -> dict          # §1.4
def generate(model, ids, hooks: list[tuple[tuple[str, int], Callable]], n: int, tokenizer, progress) -> dict
```

`generate`: greedy, `model(ids)` per step without KV cache (loaded models have `use_cache = False`), `n ≤ 64`, no
early stop (an eos shows as `∅`). One pass per side (`Clean i/n`, then `Intervened i/n` with the hooks). Hooks are
plain forward hooks on the site modules (like `lens.py`): a pre-hook on the root resets per-module call counters each
forward; the hook applies `fn` at call `k` to the output (first tensor of a tuple, the rest kept). `fn`s from
`edit_fn` rebuild their mask per call, so `"last"` follows the growing sequence. Returns the `clean` / `steered` /
`diverge` part of GenerationResult; step `top` = softmax of the last position's logits, top-5.

### 2.3 `capture.py`: `intervene` (replaces `patch`)

1. `model.eval()`; clean trace `_trace_or_raise(model, inputs)`; `_visible_ops` / `_id_maps`; `before[op]` = detached
   clone of each op's first tensor; `raw[op] = op.raw_index`; `Unknown op` for edits not in the trace.
2. Compose the fns per op (list order). `pick(ctx)` returns, for `ctx.raw_index` of an edited op, `hook(out, *, hook)`
   that checks `torch.is_tensor(out)` (else `{op} returns several tensors; edit one of its consumers`), calls the fn,
   checks the shape, remembers the returned tensor and returns it.
3. Edited trace: `tl.trace(model, args, layers_to_save="all", unwrap_when_done=True, intervene=pick)` (warnings
   silenced like `_run_trace`; the same `TraceError` wrapping except for `ValueError`, which passes through).
4. Checks: op id list equal to the clean one, else `The intervention changed the model's control flow; TorchLens
   cannot align the ops`; for every edited op the recorded out equals the returned tensor (`torch.equal`), else the
   "cannot edit" message of §1.3 with `func_name` and the first parent id.
5. For ops in `downstream` with a float tensor: `diff_row`, `tensor_stats(after)`; `after` numpy copies for `keep`;
   `logits_after = _out(output op .out)`.

`# ponytail: two full traces; store raw_index in the IR at capture to skip the clean one when big models need it`.

### 2.4 `capture_nnsight.py`: `intervene` (replaces `patch`, `PATCH`)

1. Parse op ids `address@call`; unknown or non-leaf → `Unknown op`. Order edits by (call order in a clean pass),
   compose per op.
2. Clean pass: `_trace(model, args, keep=addresses of downstream calls)` → `before[op]` from `rec.calls`.
3. Edited pass: `_Recorder(model, keep=…)` around `with NNsight(model).trace(*args) as tr:`; for each edited op in
   execution order: envoy = `reduce(getattr, address.split("."), nnsight_model)` (ModuleList children are named `0`,
   `1`, …; check on GPT-2 `transformer.h.0.mlp.c_fc`), `env.output = fn(env.output)` for call 1, inside
   `with tr.iter[call - 1]:` otherwise; `out = nnsight_model.output.save()`. Same exception unwrapping as `_trace`.
4. After values: recorded values; for an edited call `after = fn(torch.from_numpy(recorded))` (the recorder sees the
   pre-swap value, §0). Diff rows, stats, keep and `logits_after = out` as in §2.3.
